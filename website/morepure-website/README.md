# 猫谱科技官网前台

基于 `company-materials-website` 素材制作的高完成度响应式官网前台。项目采用 Next.js App Router + TypeScript，包含：首页、产品中心、产品详情、应用与解决方案、技术资料、关于、联系、询价和 404 页面。

## 本地运行

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:3000`。

生产构建：

```bash
pnpm build
pnpm start
```

## 已完成验收

- `pnpm typecheck` 与 `pnpm build` 均通过。
- 已在 1440×1000、1024×900、390×844 三种视口检查首页、产品目录与详情页，无断图或横向溢出。
- 已验证站内搜索、URL 筛选同步、询价产品/货号联动、表单成功态、移动菜单键盘操作及 4 个公开下载链接。
- 详细自动化结果见 `QA-REPORT.json`。

## 当前范围

- 产品内容由本地 TypeScript 数据驱动，适合作为视觉和内容原型。
- 询价表单包含完整前端校验和成功状态，但演示版不会发送或保存数据。
- 正式上线时建议接入 Headless CMS、询盘 API、数据库、邮件通知和权限管理。
- 资料中存在少量货号/参数写法冲突（例如 MGO/MG-O、MCDP/MCDP-、QuChERS/QuEChERS，以及 C18 pH 范围），正式发布前需由产品负责人统一复核。
- 未使用素材中带 AI 水印、草稿水印、内部价格或第三方品牌的图片和数据。
- 批次测试报告与包含待确认研究图表的资料未放入公开下载目录；桌面原始素材未作修改。
